## Findings

### 1. Two implementations of second-hand evidence ⛔ fixed

`src/trackers/secondhand.py` was written this session as **the** mechanism for
recording what somebody else observed, with the entry's own words: one thing,
not four special cases. `experiments/28-newtrackon-crosscheck.py` predates it
and still built its own dict, with its own provenance string and no constraint
on what keys it could carry.

That is the value-in-two-places defect on the concept the module exists to
own. The experiment's dict could have grown a `health_state` and nothing would
have refused it, which is exactly what `PROBE_ONLY_KEYS` is for.

**Fixed**: `experiments/28` now builds its rows through `Observation`, so both
producers of second-hand evidence go through the type that cannot emit a
health state.

### 2. The observation date was unknowable and would have been invented ⚠ fixed

Routing `experiments/28` through `Observation` immediately demanded an
`observed_at`, because the type requires one. **The committed newTrackon
snapshots carry no capture date at all**, and RULES 3.7 forbids reading one off
a file's mtime. So the honest value is a dash, and that is what a run from the
cache now writes; `--fetch` writes the instant it asked, which is the closest
thing to when the observer saw it that exists.

⭐ The type forced the question. A hand-written dict had not carried the field
at all.

### 3. The vantage gate had never seen the new record shape ⚠ checked, holds

`ProbeResult.as_record` grew four keys this session -- `dns`,
`resolved_ip_observed`, `interval`, `min_interval` -- and
`scripts/check-vantage-metadata.py` is an **expected skip** in the gate,
because a clean checkout has no health records where it looks. So the check
that validates the record shape has not run against the new shape on any push.

Driven by hand against a real record directory:

```bash
python3 scripts/check-vantage-metadata.py --path .tmp/h4
```

-> `OK  every record carries vantage metadata and a measurement rung`. No
finding, and the reason it is written down is that the gate could not have told
anybody either way.
