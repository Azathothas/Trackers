# 2026-09-05, review 3: which sentence is not backed by an artefact

Lens 3 of [`../../docs/methodology/reviews.md`](../../docs/methodology/reviews.md).

**The question:** this session wrote six entry acceptances, four claim rows,
three decision records, two reviews and a rewritten `PROGRESS.md`. **Which
sentence in any of them cannot be traced to something on disk?**

⭐ **The mechanical half was done by a script, not by reading.** reviews.md
says anything a check can assert should be, and a stale number is exactly that
shape: every `Ran N tests` claim in `TODO/` and `HISTORY/` was extracted with
its module and **the module was re-run**. Reading would not have caught the
one that had drifted, because it drifted after it was written.

## Found: my own audit script mis-attributed a count, and that is worth saying

The script pairs a `Ran N tests` claim with the nearest module named in the
three lines above it. On `TODO/measurement.md:888` it read the **whole-suite** figure in T-032's
acceptance -- `Ran 160 tests` at acceptance, from `unittest discover` -- and
attributed it to `tests.test_bep34`, reporting a mismatch against that module's
own 33.

⛔ **That is a false positive, and the underlying line is correct**: it is
marked `at acceptance` and refers to `unittest discover`, not to one module. It
is recorded here because a review that publishes its tool's output without
reading it is doing the thing this lens exists to prevent, one level up.

⚠ **The C-15 window nearly failed this audit for the wrong reason.** The
derived field `propagation_window_seconds` is **absent from run 2**, because it
was added to the instrument between run 2 and run 3. The claim is still backed
-- by the raw `rechecks` array in the same file -- but ⛔ **the three committed
results do not share a schema**, so they are not directly diffable against each
other. That is the cost of amending an instrument between runs, and it is
recorded here rather than fixed: rewriting a committed result to a newer shape
would destroy the evidence of what the instrument did at the time.
