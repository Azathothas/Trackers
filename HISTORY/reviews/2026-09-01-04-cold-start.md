# Review 4, the cold start

**Date:** 2026-09-01. **Standpoint:** a session handed exactly one instruction,
*"Read `docs/AGENTS.md` in full and follow"*, with no memory, no context and
nobody to ask.

**What I looked for:** the point at which that session is stopped, misled, or
forced to guess. Not whether the router reads well; whether following it
mechanically produces work. The router was rewritten this session, so nothing
about it is inherited evidence.

**What I did not look at:** whether the rules it routes to are correct. That is
what the previous session's cold-start pass covered
([`2026-08-31-01-cold-start.md`](2026-08-31-01-cold-start.md)), and nothing
this session changed the rules it checked.

**Method:** follow the file in order and stop at the first thing that does not
work.

---

## Findings

### 1. ⛔ Step 3 of the start-of-session sequence fails on a Windows host

`docs/AGENTS.md` section 3 says to run `python3 scripts/check-gate.py`. On the
machine this session ran on, `python3` is a store stub that prints an
advertisement and exits **49**.

**It is handled, and the handling is what makes this a pass rather than a
finding.** The instruction carries the warning and the substitution on the same
line, pointing at
[`../../docs/conventions/shell.md`](../../docs/conventions/shell.md) section 6
for the general case. ⚠ **A cold session that skipped the warning would read
the exit code as a broken repository**, which is why it is inline rather than
one link away.

### 2. ⛔ The normative rule for ending a session told the reader to break another normative rule

RULES 10.3 step 9 is the cold-start acceptance, and it said:

```text
git clone -q https://github.com/Azathothas/Trackers /tmp/coldstart
```

RULES 15.5 says, three sections later: *"No absolute paths, no `/tmp`, no shell
built-ins in a code path."*

⛔ **The file that forbids `/tmp` instructed the reader to use it**, in the
step that runs last, on a host where `/tmp` is not one directory. A session
following it on Windows either fails or writes somewhere neither it nor the
next reader can find.

**Fixed.** The command clones into `.tmp/`, which is ignored, beside the tree,
and resolves the same way on every host. It also runs one command instead of
five, because the five had drifted from the gate.

### 3. The routing table sends a reader to files that exist, which was worth checking rather than assuming

Every link in the router resolves, verified by
`python3 scripts/check-citations.py` rather than by reading. ⚠ **That check is
why three forward references to review files written later in this session were
caught**: they were links to documents that did not exist yet, and the gate
refused them until they did.

### 4. The router's own numbering has a gap, and it does not matter

Sections run 1 to 13 with no 11 missing, but the file does not have a section
between "When you are unsure" and "Something the operator will hand you" that
its earlier draft implied. ⚠ **Recorded because a numbering gap is the kind of
thing a reader reads as a missing section.** There is none: the numbering is
contiguous.

### 5. What a cold session cannot find out from the router alone

⚠ **The router does not say what the project has already tried and rejected.**
It routes to [`../decisions.md`](../decisions.md) only indirectly, through
`docs/README.md`. A session working an entry would reach it; a session about to
argue for a different language or a second measurement vantage might not, and
D1 and D2 are exactly the arguments it would be re-having.

**Not fixed, and stated rather than quietly left.** Adding a row would push the
routing table past the point where it is read in full, which is the property
the file trades everything else for. The nearest cheap improvement is that
RULES 12 and 15 both cite the decisions by id, so a reader who touches either
lands on them.

## What would have made this pass fire harder

⚠ **I wrote the file I am reviewing, in this session.** A cold reading by
somebody who did not is a different pass and this one cannot substitute for it.
What this pass could establish mechanically, it did: every link resolves, the
one command in the start sequence runs, and the two contradictions above were
found by following the text rather than by reading it.
