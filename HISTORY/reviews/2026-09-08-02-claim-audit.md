## Finding 1 -- the page that exists to stop contradictory numbers acquired a contradictory number

⛔ **And it was put there by this session.**

[`../corpus-baseline.md`](../corpus-baseline.md) opens by saying every corpus
figure is defined there and nowhere else, and it exists because **three
mutually contradictory sets of corpus numbers were once in circulation and
none came from an instrument**. This session added a DNS section to it
carrying **one** table of resolution figures -- taken on the authoring host.

The same measurement had **already been taken on the runner**, in the same
session, and disagrees:

| | runner | authoring host |
| --- | --- | --- |
| IPv4-capable hosts | 711 | 706 |
| did not resolve | 239 | 244 |
| **resolves only for the public resolver** | **3** | **11** |

⭐ **The disagreement is not noise and is not a defect: it is `C-06`'s
finding.** The whole point of `experiments/30` is that the resolver changes
the answer. So a page whose contract is "one fact, one home" had been given a
fact with two homes and shown only one of them -- and shown the one from a
vantage **no health record in this project was ever taken from**.

**How it got there:** the authoring-host run came first, the section was
written from it, and the runner run landed forty minutes later into `C-06` and
`T-007` without the earlier page being revisited. That is the ordinary way
this class happens and it is why the lens exists.

**Fixed.** The section is now **per vantage**, with the runner named canonical
because it is the vantage everything else measured from, and with a sentence
saying the split is the finding rather than a caveat. The IPv6-only figure is
called out as **identical on both**, which is what makes it safe for
[`../gates.md`](../gates.md) to quote as a corpus property.

**Also fixed, one level down:** `T-036`'s acceptance carried the same table
with no vantage named. It now names it and points at both columns.

## Finding 2 -- a denominator that was right for the wrong reason

`README.md` states our live density as **12.8% of 1327**. The numerator is
`107 + 63`, where 107 is extrapolated over the 1228 trackers unique to us and
63 is a **census** of the baseline's 99.

Checked because a mixed extrapolation-plus-census numerator over a single
denominator is exactly the shape that hides an error: **1228 + 99 = 1327**, so
the denominator is right and the two parts do not overlap. ⭐ It survives, and
it survives because the value gate computes the arms from disjoint sets rather
than because anybody chose the denominator carefully.

⚠ **What would have made this fire:** if the baseline census had been folded
into the unique-to-us arm, or if `unique_to_us` had been computed against the
raw ngosang file rather than the normalized set, the two parts would overlap
by up to 99 and the density would be overstated. Neither is true.

## What was checked and held

* **Every cited result file exists.** `check-citations.py` refuses a backticked
  path that resolves to nothing, and it is green -- which this session
  needed twice, when re-running experiments 27 and 28 changed their result
  filenames and left two entries citing files that no longer existed.
* **No figure rests on an artefact outside the tree.** Every number quoted
  today resolves to a file under `experiments/results/`, which is the failure
  this project has had before -- a baseline resting on workflow artefacts that
  had expired.
* **The test count.** Re-run rather than re-read, four times today, because it
  moved four times: 196 -> 197 -> 200 -> 202 -> 209 -> 234. `check-citations`
  caught every drift.
* **"A summary is a claim like any other."** The commit messages state gate
  results; each was run unpiped before the commit that quotes it -- except one,
  and that is the next finding.

## Finding 3 -- a commit message claimed a green gate that was red

`3731d95` says *"check-gate.py: 16 passed, 0 failed, 1 expected skip"* and it
was **not true when the commit was made**: `check-todo` was failing because
T-007's acceptance began `**Done, and the runner answered.**` where the checker
requires the literal `**Done.`. CI confirmed it red.

⛔ **The gate was run, and it was run before the edit that broke it.** That is
the whole mechanism: the message was assembled from a true reading, one more
edit landed, and the reading was not repeated. Fixed in `3a85479` with the
cause recorded in its message rather than silently.

⭐ **The check was right and the entry was the defect**, which is worth saying
because the tempting repair is to loosen the checker.
