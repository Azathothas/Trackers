# HISTORY/references

One verdict per reference. What was read, at which commit, and what this
project took from it or declined.

The corpus itself is [`../../references/`](../../references/), described by
[`../../references/PROVENANCE.md`](../../references/PROVENANCE.md). The
procedure that produced these is
[`../../docs/methodology/references.md`](../../docs/methodology/references.md),
and the cross-cutting findings are
[`../reference-sweep.md`](../reference-sweep.md).

⚠ **A verdict is a decision, not a rating.** Declining a reference in writing
is a result, because it stops the next session re-deriving the question.
